# Personal Portfolio Website (HTML Only)

## About
This is my personal portfolio website created using HTML5 without CSS. It showcases my personal information, skills, education, and other details using basic HTML elements.

## Technologies Used
- HTML5

## Features
- Personal introduction
- Profile photo
- Education details
- Skills and projects
- Contact information
- Basic HTML structure without CSS

## How to Run
1. Clone this repository:
   ```bash
   git clone GITHUB_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `portfolio.html` in any web browser.
